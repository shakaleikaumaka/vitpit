🕳️ The P.I.T. Protocol

Public Information Transmission

This site is a demo instance of the open, forkable protocol that turns a gathering's ephemeral knowledge into a permanent public good — first proven at The Esmeralda P.I.T. (149 sessions · 122 hours · 138 synced transcripts · ≈$0). This fork is where it stands today:

STAGE 1 · DONE

CRAWL

39 recordings gathered from the public Drive folder — no API keys, reproducible by anyone.

STAGE 2 · DEMO

HARVEST

Catalog + speaker tags curated. Full transcription (Whisper) is declared, not yet done.

STAGE 3 · DONE

AUDIT

Every title checked against the source listing; truncations and stream artifacts flagged honestly.

STAGE 4 · DONE

PUBLISH

This static site — no backend, ≈$0 infra. Recordings stream from the source Drive.

STAGE 5 · NEXT

CONSENT-FIRST

Nothing enters a permanent archive without explicit organizer + speaker consent. The soul of the protocol — and the next step for this pit.
